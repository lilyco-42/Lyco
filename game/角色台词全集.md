## 7. GPT-SoVITS 情感配音配置指南

### 7.1 推荐工作流

```
录制参考音频 → GPT-SoVITS 训练 → 按情绪分类推理 → 导入 Ren'Py
```

### 7.2 参考音频录制要求

- **格式**：WAV / 24bit / 48kHz / 单声道
- **时长**：每条 5-15 秒，每种情绪 3-5 条
- **环境**：安静，无混响，同一麦克风，同一声场
- **内容**：用剧中台词录制，不要用无关文本

### 7.3 每角色建议录制情绪维度

| 角色 | 核心情绪 | 次情绪 | 特殊情绪 |
|------|----------|--------|----------|
| **李可** | 平静（中性叙述，占 60%） | 温柔（对孩子/同伴）、坚定（决断时） | 脆弱（"不知道"）、顿悟（"是回信"） |
| **陈锋** | 低沉（日常，占 50%） | 硬撑（受伤时）、急切（救援时） | 脆弱（"为什么是我们"）、坚定（"应该回"） |
| **周晴** | 温柔（占 70%） | 专业（医疗时） | 迷茫（"我们要做什么"） |
| **赵明远** | 沉稳（占 80%） | 深沉（哲学独白时） | 微笑（告别时） |
| **小林** | 清澈（年轻坚定，占 60%） | 好奇（初次见面） | 温暖（提到爷爷时） |
| **工程师** | 兴奋（专业发现，占 40%） | 庄重（旅行者号独白） | 脆弱（"我怕它又没了"） |

### 7.4 GPT-SoVITS 训练配置建议

**模型选择：**
- 中文基底推荐用 `GPT-SoVITS-2024` 预训练模型
- 每个角色单独训练一个 `GPT` 模型 + `SoVITS` 模型

**训练参数：**
- `batch_size`: 4-8（取决于显存）
- `epochs`: 50-100（参考音频质量高则减少）
- `learning_rate`: 1e-4
- `text_frontend`: 中文（标配即可）

**推理参数：**
- `top_k`: 5（控制稳定性）
- `top_p`: 0.8
- `temperature`: 0.6（太低则平淡，太高则不稳定）
- `speed`: 1.0（标准语速）

### 7.5 情绪控制技巧

GPT-SoVITS 是**参考音频驱动**的，而非标签驱动。控制情绪的方法：

1. **按情绪准备参考音频**：为每个角色录制 3-5 种情绪的参考音频
2. **推理时切换参考**：同一句台词用不同情绪参考推理，得到不同语气
3. **参考音频选择建议**：

```
李可 "不知道"（同一句词需要三种情绪）：
  - 平静参考 → 平淡陈述
  - 温柔参考 → 带着安慰
  - 脆弱参考 → 带着无助

陈锋 "够了。"（同一句词需要两种情绪）：
  - 低沉参考 → 自我说服
  - 坚定参考 → 真的够了
```

### 7.6 Ren'Py 集成方式

Ren'Py 使用 `.ogg` 格式音频，推荐两种集成方式：

**方式 A — 整句预渲染（推荐）：**
对所有台词按情绪批量生成，导出为 `voice/lk_001.ogg`，在每句前加：

```renpy
voice "voice/lk_001.ogg"
lk "这句台词。"
```

**方式 B — 实时 TTS（不推荐用于游戏）：**
延迟不可控，且 GPT-SoVITS 不适合实时推理。

### 7.7 优先级建议

1. **先录李可** — 台词最多（95 句），需最精细的情绪分层
2. **再录陈锋** — 40+ 句，情绪跨度大
3. **再录 NPC** — 各角色台词较少，每角色 3-5 句参考音频即可
4. **周晴 / 赵明远** — 台词少，集中录制

### 7.8 文件命名规范建议

```
voice/
├── lk_001_平静.ogg
├── lk_002_温柔.ogg
├── lk_003_坚定.ogg
├── cf_001_低沉.ogg
├── cf_002_急切.ogg
├── zq_001_温柔.ogg
└── zq_002_专业.ogg
```

台词与文件名对照表另建 `voice_mapping.csv` 管理，格式：

```
文件路径,章节,角色,台词,情绪
voice/lk_001.ogg,序章,lk,嗯。,平静
voice/lk_002.ogg,序章,lk,什么事？,追问
```
