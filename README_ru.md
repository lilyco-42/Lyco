# lyco

LAN IP сканер + P2P мессенджер — обнаружение хостов, подключение к пирам, чат с верифицированной цепочкой сообщений.

## Возможности

- **LAN сканирование** — ping sweep, сканирование TCP портов, автоопределение подсети
- **P2P чат** — прямое TCP соединение на порту 4242, комнатный обмен сообщениями
- **SHA256 цепочка** — каждое сообщение связано с предыдущим через хеш, защита от подделки
- **Кроссплатформенность** — Windows, Linux, macOS
- **i18n** — русский / китайский / английский, автоопределение

## Установка

### cargo-binstall

```bash
cargo binstall lyco
```

### Прямая загрузка

Выберите платформу на [Releases](https://github.com/lilyco-42/Lyco/releases).

### Windows MSI

Скачайте `lyco-x86_64-pc-windows-msvc.msi` и установите двойным кликом.

### Сборка из исходников

```bash
git clone https://github.com/lilyco-42/Lyco.git
cd Lyco
cargo build --release
```

## Использование

```bash
lyco
```

1. **CIDR** определяется автоматически по сетевому интерфейсу — можно изменить
2. Нажмите **Начать сканирование** для поиска хостов
3. Нажмите **Подключиться** на активном хосте для установки P2P
4. Общайтесь в комнатах, сообщения проверяются SHA256 цепочкой

## Архитектура

```
src/
├── main.rs      # Точка входа, определение локали
├── mod.rs       # Объявления модулей
├── core.rs      # Чистая логика — движок сканирования, P2P протокол
└── gui.rs       # egui интерфейс — панель настройки, результаты, чат
```

**Core** не имеет GUI зависимостей. **GUI** вызывает логику через `crate::core::*`.

### P2P протокол

Формат JSON-строк поверх TCP, каждое сообщение связано с предыдущим через SHA256:

```
{"msg_id":1, "room":"default", "payload":"привет", "prev_hash":"genesis"}
{"msg_id":2, "room":"default", "payload":"мир", "prev_hash":"a1b2c3..."}
```

Оба пира проверяют `prev_hash` при получении. Нарушение цепочки → сообщение отклоняется.

### Движок сканирования

Многопоточность: диапазон IP делится на N воркеров. Каждый воркер:
- Использует общий `surge_ping::Client` (один ICMP сокет)
- `TcpStream::connect_timeout` для сканирования портов
- Результаты передаются в GUI в реальном времени через `mpsc::channel`

## Зависимости

Чистый Rust стек — без OpenSSL:

| Крейт | Назначение |
|-------|---------|
| `eframe` / `egui` | GUI |
| `surge-ping` | ICMP ping |
| `sha2` | SHA256 хеширование |
| `serde` / `serde_json` | Сериализация сообщений |
| `getifaddrs` | Определение сетевых интерфейсов |
| `rust-i18n` | Интернационализация |
